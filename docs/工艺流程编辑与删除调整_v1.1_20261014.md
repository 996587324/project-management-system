# 工艺流程编辑与删除调整 v1.1

日期：2026-10-14。新增迭代说明，保留原开发文档。

## 问题与调整

原界面仅通过双击打开节点编辑、双击细连线删除；节点按下时立即把指针捕获到 SVG 根画布，可能干扰后续节点双击事件。入口不明显，也不便于触屏操作。

本次改为：

- 有配置权限时，流程区域提供“编辑流程”按钮，进入原页面的布局/流程编辑模式。
- 单击工序或连线选中并高亮，工具条显示当前对象，提供明确的编辑和删除按钮。
- 工序可编辑名称和关联卡片；空白名称不会被保存。
- 连线可修改起始和目标工序，禁止自连线、缺失节点及重复的同方向连线。
- 连线增加透明点击区域，避免必须精确点击两像素细线。
- 删除工序/连线需要确认；删除工序会同时清理相连的连线，不删除关联参数卡片。
- 查看模式不显示编辑/删除工具；退出编辑时关闭弹窗，修改方法也会检查编辑状态。
- 只有实际拖动超过四像素才进行指针捕获，单击和双击保留原节点目标。
- 编辑、删除先作用于当前编辑草稿，最后点击页面顶部“保存布局”持久化；“取消编辑”仍恢复原配置。
