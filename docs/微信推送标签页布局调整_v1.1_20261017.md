# 微信推送标签页布局调整 v1.1

日期：2026-10-17。本次仅调整前端布局，不修改后端、数据库或动态路由。

## 页面变化

「我的微信推送」由纵向堆叠改为五个标签页：

- 微信绑定：扫码绑定、状态、MCP 推送授权和解绑。
- AI 连接配置：原有密钥、额度、Agent 配置和 AI 处理记录。
- 收发测试：输入消息并发送测试。
- 接收记录：接收消息与独立分页。
- 发送记录：投递结果、耗时、失败原因与独立分页。

顶部统一展示绑定状态、刷新按钮、五秒自动刷新开关及刷新异常。标签内容独立滚动，长配置不再挤占其他业务区域；颜色沿用系统主题变量。

默认打开微信绑定。扫码成功后点击「开始消息测试」切到收发测试标签。切换标签不清空输入、表单和分页；AI 配置首次打开才加载，加载后沿用原有状态刷新。
