# 首次路由加载刷新修复：测试用例结果

测试日期：2026-10-24（北京时间）

结论：本轮执行 14 个测试用例，14 个通过，0 个失败，0 个阻塞。A/B 两种模式下，测试页面首次加载及重复切换均未发生整页刷新。

## 测试范围与环境

- 前端：当前工作区源码，Vite 7.3.6，Vue Router，Element Plus。
- A 模式：development，独立端口 31996；B 模式：system-b，独立端口 31997。
- 两个模式各自使用本轮新建的空依赖缓存目录，先完成启动预构建，再开始浏览器操作；未复用上次验证缓存。
- 测试组件：真实小时产量配置、真实工艺看板配置、真实小时产量看板、真实富文本组件，均通过动态路由导入。
- 业务接口使用内存模拟数据，不连接或写入真实业务数据库；未执行真实账号登录、全量菜单权限或全项目业务回归。
- 测试进程配置 512 MB 老生代上限及 8 MB 半空间，A/B 顺序测试，避免额外内存压力。本轮未发生进程内存不足退出。
- 用户要求关闭的 3006、3007 已先关闭，测试完成后确认仍关闭。

## 判定方式

测试根组件在每次文档重新执行时增加 sessionStorage 启动计数；路由正常切换不增加计数。每个首次加载步骤都检查目标页面可见、启动次数为 1、根组件测试草稿仍与输入一致，并保存完整页面状态。

草稿是测试根组件中的内存输入，用于检测整页重载。此用例不表示所有业务表单离开路由后都会自动缓存，也未验证所有菜单的 keep-alive 行为。
