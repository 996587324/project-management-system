| 模块 | 原先问题 | 本次调整 |
| --- | --- | --- |
| 设备卡片看板 | 白色背景、深色文字、蓝色强调固定 | 页面、卡片、统计卡、AI 建议条、详情文字改用主题变量；保留在线、故障等状态语义 |

| Agent、PDA、微信 ClawBot 部分页面 | 使用未定义的 `--art-text-gray-*` | 改为已定义且支持明暗切换的 `--art-gray-*` |
| 系统 B 工作台、系统配置、系统入口 | 辅助文字固定灰色 | 改为系统辅助文字变量 |

## 二、公开页面与后台页面的隔离

公开页面仍为 `/public/production-dashboard`，由原有 `route.meta.publicReadOnly` 决定公开只读状态。

- 后台生产看板根节点不是 `.production-dashboard--public` 时，注入 `--pd-*` 主题变量。
- 共用组件保留原颜色作为 CSS 变量的回退值；公开页面不注入这些变量，保持原独立配色。
- `DashboardWidgetRenderer.vue` 在 `publicAccess=true` 时不应用后台图表主题。
- 不修改 `RobotLineScene.vue`、模型材质、用户配置的物体/字段颜色、二维码黑白配色和状态判定规则。
- 未改变公开页登录、只读、权限、路由和接口逻辑。

## 三、新增基础能力

### 1. 业务主题样式

新增 `src/assets/styles/core/business-theme.scss`，在 `src/assets/styles/index.scss` 引入：

- `--business-radius` 读取现有 `--custom-radius`。
- `--business-card-shadow` 根据现有 `data-box-mode` 切换阴影。
- `--pd-*` 将后台生产监控页面的颜色映射到现有 Element Plus 主题变量。
- 不增加独立主题存储，不改变 A/B 系统现有设置持久化机制。

### 2. 图表颜色补丁

新增：

- `src/utils/ui/business-chart-theme.ts`：生成只包含外观颜色的 ECharts 补丁。
- `src/hooks/core/useBusinessChartTheme.ts`：监听明暗和主色变化，更新已注册的图表；支持完整包和按需 core 包的图表实例。

主题变化不会重新请求业务数据、销毁重建图表，也不写入数据、图例选择、缩放范围和用户设置的系列颜色。正常业务数据刷新沿用原有逻辑。

接入位置：

- `src/views/dashboard/console/index.vue`
- `src/views/edge-gateway/data-trace/index.vue`
- `src/views/process-board/components/ParameterTrends.vue`
- `src/views/production-dashboard/components/DashboardWidgetRenderer.vue`
